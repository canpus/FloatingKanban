# 悬浮任务看板 FloatingKanban

一个悬浮在桌面上的半透明任务看板小组件（WPF，纯 C# 单文件，无任何依赖）。

## 使用

双击 `FloatingKanban.exe`。数据自动保存在 `%APPDATA%\FloatingKanban\data.json`，关闭重开自动恢复。程序会同时常驻系统托盘（右下角小图标）：双击托盘图标显示/隐藏看板，右键托盘图标可退出。

## 功能

- 三列看板：待办 / 进行中 / 已完成，每列带任务计数
- **添加任务**：底部输入框输入，回车或点「＋ 添加」；输入框左侧的下拉按钮选择新任务加入的列
- **管理任务**：
  - **拖动卡片** → 在列内排序或跨列移动，蓝色横线指示落点
  - **右键点卡片** → 置顶 / 编辑 / 删除
  - 双击卡片文字 → 修改内容（回车保存，Esc 取消）
  - 点左侧圆圈 → 一键完成/取消完成；已完成任务自动划线置灰
  - 鼠标悬停卡片 → 自动展开显示全部内容（平时最多显示两行，超出省略）
  - 「已完成」列右上角「清空」→ 一键清空已完成任务
- **窗口控制**（右上角）：📌 置顶开关、◐ 调透明度、⇩ 导出、— 收起为小胶囊、✕ 退出
- **时间记录与导出**：
  - 每条任务自动记录录入时间和最近一次完成时间（拖出去重做会刷新完成时间）
  - 已完成卡片右下角显示完成时间；悬停卡片可在提示里看到创建/完成时间
  - 右上角 ⇩ → 导出本周 / 本月 / 本季度 / 自定义时间段的已完成任务为 CSV（UTF-8 带 BOM，Excel 直接打开不乱码），按完成时间排序，含「完成时间、任务内容、录入时间、用时(天)」，方便写周报月报
- 按住标题栏或列头拖动窗口，位置、大小、透明度、任务全部自动记住

## 重新编译

双击 `build.bat`（使用 Windows 自带 .NET Framework 编译器，无需安装任何东西）。
图标文件 `app.ico` 由 `make_icon.ps1` 生成，改了图标脚本后重新生成：
`powershell -ExecutionPolicy Bypass -File make_icon.ps1`

## 开机自启（可选）

`Win + R` 输入 `shell:startup`，把 `FloatingKanban.exe` 的快捷方式放进去。

## 关于 360 报毒（误报）

本程序是纯本地小工具：**不联网、无驱动、不写注册表**，全部源码就在 `Kanban.cs`，数据只存在 `%APPDATA%\FloatingKanban\data.json`。360 的 QVM「人工智能引擎」对**无数字签名的未知小体积 exe** 有大量已知误报。

已做的无害化处理：补全了文件版本信息（公司/产品/版本号）、嵌入正规多尺寸图标、manifest 显式声明 asInvoker（不要求提权）。

如果仍被拦截：
1. 打开 360 →「木马查杀」→「信任区」，把 `FloatingKanban.exe` 添加为信任文件；
2. 如果文件已被隔离，先在「恢复区」恢复，再加信任；
3. 可用 `certutil -hashfile FloatingKanban.exe SHA256` 计算指纹，确认每次自己编译的文件一致；
4. 也可向 360 提交误报反馈（产品里自带「误报反馈」入口），一般 1-2 个工作日会加白。
