# 悬浮任务看板 FloatingKanban 2.0

悬浮在桌面上的任务看板小组件（WPF，纯 C# 单文件，无任何第三方依赖，程序约 120 KB）。

## 使用

双击 `FloatingKanban.exe`。数据自动保存在 `%APPDATA%\FloatingKanban\data.json`，关闭重开自动恢复。程序同时常驻系统托盘：双击托盘图标显示/隐藏看板，右键托盘图标可切换置顶或退出。

## 功能

- 三列看板：待办 / 进行中 / 已完成，每列带任务计数
- **添加任务**：顶部输入框输入后回车或点「＋」；输入框左侧的彩色标签选择新任务加入的列（会被记住）
- **卡片操作**
  - 点卡片左侧圆圈：完成 / 取消完成，已完成任务划线置灰并显示完成时间
  - 双击卡片文字：修改内容（Enter 保存，Esc 取消）
  - 右键卡片：置顶 / 编辑 / 删除；删除后底部提示条可「撤销」
  - 鼠标悬停卡片：展开全部内容；停留片刻显示创建 / 完成时间
- **多选与拖动**
  - 在列的空白处按住拖动：框选多张卡片（可跨列）
  - Ctrl（或 Shift）+ 单击：逐张加选 / 取消
  - 拖动任意已选卡片：所有选中卡片一起移动，卡片跟随鼠标，落点处出现虚线占位；拖到列表上下边缘会自动滚动；Esc 取消拖动或清除选择
  - 多选后右键：批量置顶 / 批量删除
- **归档与完成记录**
  - 「已完成」列右上角「归档」：把已完成任务移出看板，记录永久保留，导出时仍会包含；可撤销
- **导出 CSV**（右上角下载图标）
  - 本周 / 上周 / 本月 / 上月 / 本季度，菜单里直接显示每个时间段的条数
  - 自定义时间段：日历上依次点开始、结束日期
  - 内容：完成时间、任务内容、录入时间、用时(天)；UTF-8 带 BOM，Excel 直接打开不乱码；会记住上次保存的文件夹
- **窗口**
  - 右上角按钮：置顶、不透明度、背景颜色、语言、导出、收起为胶囊、退出；鼠标悬停显示按钮名称
  - 按住标题栏或列标题拖动窗口；右下角拖动调整大小
  - 收起为胶囊 / 展开：同一个外框连续形变并滑到目标位置
  - 胶囊可随意拖动；拖到屏幕左 / 右 / 上 / 下边缘松手会吸附并藏进边缘，只露出一条细边，鼠标移上去自动滑出，移开后再藏回
  - 窗口位置与大小、胶囊位置、是否贴边、展开/收起状态、置顶、不透明度、背景色全部自动记住
- **语言**：繁体中文（zh-TW，默认）/ 简体中文（zh-CN）/ English（en-US），切换即时生效并自动记住

## 数据安全

- 保存时先写临时文件再替换，并保留上一版 `data.json.bak`，写入中途断电不会损坏数据
- 若 `data.json` 损坏，会先另存一份 `data.corrupt-时间.json`，再自动从 `.bak` 恢复
- 旧版（1.x）的 `data.json` 可直接读取，任务、时间记录、位置和颜色都会沿用

## 重新编译

双击 `build.bat`（使用 Windows 自带的 .NET Framework 编译器，无需安装任何东西）。
图标文件 `app.ico` 由 `make_icon.ps1` 生成，改了图标脚本后重新生成：
`powershell -ExecutionPolicy Bypass -File make_icon.ps1`

界面图标使用系统自带的 Segoe Fluent Icons（Windows 11）/ Segoe MDL2 Assets（Windows 10）字体，不占程序体积。

## 开机自启（可选）

`Win + R` 输入 `shell:startup`，把 `FloatingKanban.exe` 的快捷方式放进去。

## 关于 360 报毒（误报）

本程序是纯本地小工具：**不联网、无驱动、不写注册表**，全部源码就在 `Kanban.cs`，数据只存在 `%APPDATA%\FloatingKanban\`。360 的 QVM「人工智能引擎」对**无数字签名的未知小体积 exe** 有大量已知误报。

已做的无害化处理：补全了文件版本信息（公司/产品/版本号）、嵌入正规多尺寸图标、manifest 显式声明 asInvoker（不要求提权）。

如果仍被拦截：
1. 打开 360 →「木马查杀」→「信任区」，把 `FloatingKanban.exe` 添加为信任文件；
2. 如果文件已被隔离，先在「恢复区」恢复，再加信任；
3. 可用 `certutil -hashfile FloatingKanban.exe SHA256` 计算指纹，确认每次自己编译的文件一致；
4. 也可向 360 提交误报反馈（产品里自带「误报反馈」入口），一般 1-2 个工作日会加白。
